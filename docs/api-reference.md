# API Endpoints

| Endpoint        | Method  | Description                        |
|:----------------|:-------:|:-----------------------------------|
| /plants         |   GET   | Get a list of all plants           |
| /plants/{id}    |   GET   | Get details of a specific plant    |
| /plants         |  POST   | Add a new plant                    |
| /plants/{id}    |   PUT   | Update plant details               |
| /plants/{id}    | DELETE  | Remove a plant                     |
| /compounds      |   GET   | Get a list of active compounds     |
| /compounds/{id} |   GET   | Get details of a specific compound |
| /uses           |   GET   | Retrieve medicinal uses            |
| /preparations   |   GET   | Retrieve preparation methods       |
