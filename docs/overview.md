# Medicinal Plants API Documentation

## Overview

The **Medicinal Plants API** is a RESTful service built with **Spring Boot** that stores and manages information about medicinal plants, their active compounds, medicinal uses, and preparation methods. The project is based on The Encyclopedia of Medicinal Plants by Andrew Chevallier and aims to provide structured, accessible data for herbal medicine research and personal reference.

## Features

- RESTful API with CRUD operations for medicinal plants

- Database schema designed for scalability and efficiency

- Spring Boot, Spring Data JPA, and PostgreSQL support

- DTOs for structured API responses

- Unit tests for reliability
